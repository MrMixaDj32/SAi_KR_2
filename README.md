# Мультиагентная система адаптивного управления светофорным регулированием (SAi_KR_2)

[![.NET 8.0](https://img.shields.io/badge/.NET-8.0-blue.svg)](https://dotnet.microsoft.com/)
[![Language: C# 12](https://img.shields.io/badge/Language-C%23%2012-green.svg)](https://docs.microsoft.com/en-us/dotnet/csharp/)
[![Platform: Windows Forms](https://img.shields.io/badge/Platform-WinForms-orange.svg)](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/)
[![Tests](https://img.shields.io/badge/Tests-44%2F44%20Passing-brightgreen.svg)]()

Программный комплекс имитационного микромоделирования и адаптивного светофорного регулирования транспортного коридора (на примере участка ул. Северной в г. Краснодаре от ул. Октябрьской до ул. Красной).

---

## Основные возможности

- **Микромоделирование движения (IDM):**
  - Реализация расширенной модели Intelligent Driver Model (Treiber & Kesting);
  - Индивидуальная кинематика ускорения, торможения и следования за лидером;
  - Сглаженная интерполяция поворотов ТС по сплайновым траекториям 53 полос движения;
  - Защита от блокировки перекрестков (Anti-Gridlock, п. 13.2 ПДД РФ).

- **Мультиагентное управление:**
  - Децентрализованные агенты перекрестков (`TrafficAgent`);
  - Искусственная нейронная сеть прямого распространения (MLP 8-8-1) с вещественными весами;
  - Оценка градиента давления (Max-Pressure), локальных очередей и средней скорости потока;
  - Межагентная координация («зеленая волна») для беспрепятственного пропуска взводов транспорта.

- **Продукционная база правил безопасности (`SafetyRuleEngine`):**
  - Строгое соблюдение нормативных ограничений ГОСТ Р 52289-2019;
  - Контроль минимальной длительности фаз ($t_{\text{min}}$) и максимального удержания ($t_{\text{max}}$);
  - Промежуточные переходные интервалы безопасности (Yellow = 3.0 с, All-Red = 2.0 с);
  - Досрочный сброс пустых фаз второстепенных улиц (Early Cut-off);
  - Защита магистральных пачек автомобилей при попытке несвоевременного переключения.

- **Обучение агентов:**
  - Встроенный генетический алгоритм с вещественным кодированием генома;
  - Оптимизация 243 синаптических весов за 15 поколений по целевой функции минимизации задержек и заторов.

- **Сравнительный анализ (Лабораторный A/B тест):**
  - Детерминированное моделирование при идентичном генераторе псевдослучайных чисел (`seed = 42`);
  - Объективное сопоставление жесткого цикла ГОСТ и адаптивного Мультиагентного ИИ;
  - Сводная аналитическая ведомость и визуализация гистограмм задержек с экспортом в буфер обмена.

## Архитектура решения

```
SAi_KR_2/
├── Program.cs                 # Точка входа, High-DPI, встроенный раннер тестов (--test, --bench)
├── Form1.cs                   # Главное окно, GDI+ визуализация, HUD-панели перекрестков
├── Form1.Designer.cs          # Компоновка интерфейса WinForms
├── SimulationEngine.cs        # Физический движок, топология 53 полос ул. Северной, расчет коллизий
├── Vehicle.cs                 # Кинематическая модель автомобиля (IDM)
├── Lane.cs                    # Геометрия полос движения, сплайны точек, кэш длины
├── Intersection.cs            # Модель перекрестка, фазовые переходы, ExtendedGreenLimit
├── TrafficAgent.cs            # Мультиагентный контроллер перекрестка, векторное состояние
├── NeuralNetwork.cs           # Нейросеть MLP 8-8-1 с функциями активации tanh и сигмоида
├── SafetyRuleEngine.cs        # Продукционная база правил безопасности (ГОСТ, Anti-Gridlock)
├── GeneticTrainer.cs          # Генетический алгоритм оптимизации весов нейросетей
├── EvolutionRunner.cs         # Фоновый раннер поколений генетического алгоритма
├── ComparisonRunner.cs        # Модуль детерминированного A/B эксперимента (seed=42)
└── ComparisonReportForm.cs    # Форма отчета сравнительного тестирования с графиками
```

## Сборка и запуск

### 1. Сборка проекта
```bash
dotnet build
```

### 2. Запуск встроенных модульных тестов (44 теста)
```bash
dotnet run --no-build -- --test
```

### 3. Экспресс-бенчмарк производительности
```bash
dotnet run --no-build -- --bench
```

### 4. Запуск графического приложения
```bash
dotnet run
```
